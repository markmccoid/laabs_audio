# Book Transcripts Require iOS 26 SpeechAnalyzer

Book Transcripts (whole-audiobook transcription for Read-Along and Transcript EPUB Export) are generated exclusively with the iOS 26 SpeechAnalyzer/SpeechTranscriber API, and the feature is runtime-gated to iOS 26+. We deliberately do not extend the existing SFSpeechRecognizer path (ADR-0003's Clip Transcription module) to whole books, even though it would cover older iOS versions: SFSpeechURLRecognitionRequest has a roughly one-minute practical limit, so a whole-book pipeline on it would require an AVAssetExportSession chunker with chunk-boundary word loss, timestamp re-offsetting, and materially worse punctuation — the largest source of accidental complexity in the original design, producing the worst transcripts. SpeechAnalyzer ingests arbitrarily long files directly, runs faster than real time on device, and emits the word-level timings the future Read-Along milestone needs, so those timings are persisted from the first release. If demand appears on older devices, a chunked SFSpeechRecognizer fallback can be added later as a purely additive path; do not "fix" the missing fallback without revisiting this trade-off.
