Developer Handbook

LAABS Audio

An Expo / React Native audiobook player for self-hosted Audiobookshelf servers — built for real offline listening, with downloads, durable progress sync, and a SQLite read model that keeps very large libraries fast.

📓
What this handbook is

A curated, distilled tour of the app's architecture for developers. It summarizes the working notes in docs/*.md into accessible pages with diagrams. The markdown files remain the detailed source of truth; this site is the front door.

What the app does

  • Streamed & downloaded playback — stream from an Audiobookshelf server, or play fully offline from downloaded files (downloaded-first resolution).
  • Durable progress sync — listening position is reconciled across caches and queued offline, then flushed on reconnect; nothing is lost when you lose signal.
  • Home shelves — derived shelves, user custom shelves, and Audiobookshelf playlist shelves on one Home tab.
  • Bookmarks, sleep timer, ambient audio — listening quality-of-life features layered around the player.
  • Multiple sign-ins & libraries — remembered user sessions with sign-in switching and explicit library activation.

Tech stack

Expo SDK 56 React Native 0.85 React 19.2 Expo Router react-native-audio-pro (local module) TanStack Query v5 Zustand v5 expo-sqlite react-native-mmkv v4 Uniwind FlashList v2 Reanimated v4

State is split deliberately: SQLite is the read model for large library data, TanStack Query + MMKV holds server/user state and persisted caches, and Zustand holds live UI/playback state. See Architecture for how these fit together.
