App: LAABS Audiobookshelf
Bundle ID: com.markmccoid.laabs-audio

Target audience:
- Existing Audiobookshelf users

Positioning:
- Market explicitly as an Audiobookshelf app, not a generic audiobook app
- Lead with differentiated listening features over general library browsing

Brand colour:
- Forest Green (#1F6F43)
- Chosen from the app's default accent colour so the screenshot set stays on-brand while giving the mostly light UI strong contrast

Confirmed benefits:
1. DOWNLOAD FOR TRUE OFFLINE LISTENING
2. BUILD CUSTOM SHELVES IN AUDIOBOOKSHELF
3. ADD AMBIENT SOUND TO ANY BOOK

Why these were chosen:
- Downloads and offline playback are the clearest user benefit
- Custom shelf creation that saves back as Audiobookshelf playlists is a strong differentiator
- Ambient audio is uncommon enough to stand out in App Store screenshots
